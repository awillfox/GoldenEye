# GoldenEye — CLAUDE.md

## Project

Self-hosted NVR in Go. Two processes:
- **mediamtx** — ingests RTSP from IP cameras (one connection per cam), records fMP4 segments, serves HLS
- **goldeneye** — control plane: auth, dashboard, camera CRUD, recording index, rotation, HLS proxy

## Stack

| Layer | Library |
|-------|---------|
| HTTP | `go-chi/chi/v5` + `go-chi/render` |
| DB | PostgreSQL via `pgx/v5/pgxpool` |
| Queries | sqlc (generated, never edit `sqlc/` by hand) |
| Schema | Atlas (`schema.hcl` is source of truth) |
| Config | viper (reads `.env` as dotenv + env vars) |
| Auth | bcrypt + `golang-jwt/jwt/v5` (HMAC, cookie) |
| Templates | `html/template` + Tailwind CSS + hls.js |
| Tasks | `Taskfile.yml` — use `task <name>` not raw commands |

## Key Files

```
main.go                      bootstrap, wire all deps, graceful shutdown
schema.hcl                   Atlas schema (source of truth for DB)
schema.sql                   generated by task generate-sql-schema
sqlc.yaml                    sqlc config
internal/config/env.go       .env loader via viper dotenv
internal/config/settings.go  config.json atomic read/write (RWMutex)
internal/auth/               bcrypt, JWT, chi middleware, role guard
internal/camera/service.go   CRUD + mediamtx reconcile
internal/mediamtx/client.go  mediamtx HTTP API client
internal/index/indexer.go    scan RECORDINGS_DIR → upsert recordings table
internal/rotation/sweeper.go hourly delete rows+files older than retention_days
internal/web/server.go       chi router + all handlers
internal/web/templates/      html/template pages (parsed fresh per request)
internal/web/static/         app.css (Tailwind), hls.min.js (embedded)
```

## Rules

- **Never edit `sqlc/`** — run `task sqlcgen` to regenerate after SQL changes
- Schema changes: edit `schema.hcl` → `task migrate-dev` → `task generate-sql-schema` → `task sqlcgen`
- New SQL query: add to `internal/sql/<feature>.sql` → `task sqlcgen` → commit both in same commit
- Templates parsed per-request (not cached) — each page file gets base.html + page.html parsed together
- Settings (retention_days, segment_minutes) live in `config.json`, NOT the DB
- Infra secrets live in `.env`, never in `config.json`
- `MASTER_KEY` signs JWT only; bcrypt uses its own salt (no pepper)
- RTSP credentials stored plaintext in DB (known limitation, TODO: AES-GCM)

## Common Tasks

```bash
task run              # go run . with .env loaded
task dev              # mediamtx + tailwind watch + go run
task css              # build Tailwind CSS + download hls.js if absent
task migrate-dev      # apply schema.hcl to PSQL_URL
task generate-sql-schema  # inspect DB → regenerate schema.sql
task sqlcgen          # regenerate sqlc/ from internal/sql/ + schema.sql
task build            # CGO_ENABLED=0 static binary → bin/goldeneye
task test             # go test ./...
```

## Deploy (to remote)

```bash
task build
rsync bin/goldeneye bin/mediamtx mediamtx.yml config.json user@host:/deploy/dir/
# copy .env with adjusted PSQL_URL host and RECORDINGS_DIR
# systemd services: mediamtx.service + goldeneye.service
# goldeneye needs AmbientCapabilities=CAP_NET_BIND_SERVICE for port < 1024
```

## Architecture Notes

- mediamtx paths managed dynamically via API — GoldenEye reconciles on startup and camera CRUD
- Recorder: mediamtx native (`record: true` per path), not a separate ffmpeg process
- HLS live view: on-demand (mediamtx muxer spins up on first viewer), proxied behind auth at `/hls/{name}/*`
- Indexer scans `RECORDINGS_DIR` every 2 min, upserts `recordings` table (path unique)
- Rotation: hourly ticker, `DELETE FROM recordings WHERE started_at < now() - make_interval(days => N) RETURNING path` then `os.Remove`
- Settings written atomically: tmp file → `os.Rename`, guarded by `sync.RWMutex`
- Admin bootstrap: if `users` table empty on startup, create admin from `ADMIN_USER`/`ADMIN_PASS` in `.env`
